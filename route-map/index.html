01 / Route data

Separate routes with commas or new lines. Chains: AKL-ZQN-SYD. One to many: AKL-ZQN/SYD/MEL. Add #rrggbb to colour a route or group.

Up to 5 MB and 2,000 rows. Excel uses the first worksheet. Required columns: origin, destination.

Columns and airport codes

Optional: flights, seats, airline, colour (or color, as #rrggbb), origin_lat, origin_lon, destination_lat, destination_lon. Flights and seats must be non-negative numbers. Use the same period for every row.

Coordinates use decimal degrees (longitude −180 to 180, latitude −90 to 90). Supply both for codes outside the lookup, or to override a location.

The lookup uses the repository airport table (9,803 airports). IATA and ICAO codes are accepted. Coordinates in your file override the lookup.

Rows for the same airport pair are added together, including both directions. Airline filtering happens before adding. Missing values are never treated as zero.
