Your network, on a map.

Turn a route table into a map for a report or presentation. Your files stay in this browser.

01 / Route data

Up to 5 MB and 2,000 rows. Excel uses the first worksheet. Required columns: origin, destination.

Sample CSVSample Excel
Columns and airport codes

Optional: flights, seats, airline, origin_lat, origin_lon, destination_lat, destination_lon. Flights and seats must be non-negative numbers. Use the same period for every row.

Coordinates use decimal degrees (longitude −180 to 180, latitude −90 to 90). Supply both for codes outside the built-in list, or to override a location.

Built-in codes: AKL, WLG, CHC, ZQN, DUD; SYD, MEL, BNE, OOL, CBR, PER, ADL, HBA, CNS; DUB, ORK, SNN, NOC, KIR.

Rows for the same airport pair are added together, including both directions. Airline filtering happens before adding. Missing values are never treated as zero.
